# 🎮 Tic-Tac-Toe Game

A simple and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. Two players can play the game by taking turns marking the 3×3 grid with X and O.

## 📌 Features

- 🎯 Simple and user-friendly interface
- 👥 Two-player gameplay
- ❌ Player X and ⭕ Player O
- 🏆 Automatic winner detection
- 🔄 Reset Game functionality
- 🆕 New Game option after winning
- 📱 Responsive layout

## 🛠️ Technologies Used

- **HTML5** – Structures the game interface.
- **CSS3** – Styles the game board, buttons, and layout.
- **JavaScript** – Handles player turns, winning conditions, and game reset functionality.

## 🎮 How to Play

1. Open the game.
2. Player O makes the first move.
3. Player X takes the next turn.
4. Players continue taking turns until one player completes a winning pattern.
5. The game displays the winner when three matching marks appear in a row, column, or diagonal.
6. Click **New Game** or **Reset Game** to play again.

## 🏆 Winning Conditions

A player wins by placing three matching marks in any of these patterns:

- Three horizontal cells
- Three vertical cells
- Two diagonal patterns
